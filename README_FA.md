# FineVPN یکپارچه — نسخه بازنویسی‌شده

این بسته سه جزء را در یک پروژه و یک شبکه اجرا می‌کند:

1. **Mini App + API** در `app.py` و `index.html`
2. **ربات تلگرام** در `bot.py`
3. **پنل اصلی VLESS و درگاه Subscription** که سورس آن از پروژه ارسالی شما آمده (`main.py`، `pages.py` و ماژول‌های وابسته)

همه فایل‌های پروژه در ریشه همین ZIP قرار دارند؛ هیچ پوشه پروژه تو‌در‌تو وجود ندارد. Docker Compose از یک Dockerfile و سه build target برای اجرای اجزای پایتون استفاده می‌کند. ربات و API از یک SQLite مشترک استفاده می‌کنند؛ پنل اصلی فضای ذخیره‌سازی جدا و پایدار خودش را دارد.

## راه‌اندازی یک‌فرمانی

1. دو رکورد DNS از نوع `A` بساز و هر دو را به IP عمومی سرور AWS وصل کن:
   - دامنه اصلی، برای Mini App (مثلاً `vpn.example.com`)
   - زیردامنه پنل و لینک‌های Subscription (مثلاً `panel.example.com`)
2. روی سرور پورت‌های TCP `80` و `443` را در فایروال/Security Group باز کن.
3. نصب کن: Docker Engine و افزونه Docker Compose.
4. ZIP را روی سرور در یک پوشه استخراج کن. وارد همان پوشه شو.
5. فایل نمونه را کپی کن: `cp .env.example .env`
6. در `.env` این موارد را کامل کن:
   - `BOT_TOKEN`: توکن تازه‌ای که از BotFather گرفته‌ای
   - `DOMAIN`: دامنه Mini App
   - `VPN_PANEL_DOMAIN`: زیردامنه پنل/Subscription
   - `WEBAPP_URL`: دقیقاً `https://` به‌همراه دامنه Mini App و `/`
   - `PANEL_PUBLIC_URL`: دقیقاً `https://` به‌همراه دامنه پنل
   - `SECRET_KEY`: کلید تصادفی ۶۴ کاراکتری هگز
   - `VPN_PANEL_ADMIN_USERNAME` و `VPN_PANEL_ADMIN_PASSWORD`: اطلاعات ورود مدیر پنل اصلی
7. اجرا کن:

   ```bash
   chmod +x start.sh stop.sh logs.sh backup.sh
   ./start.sh
   ```

`start.sh` فایل تنظیمات را بررسی می‌کند، پیکربندی Compose را اعتبارسنجی می‌کند و چهار سرویس `vpn-panel`، `api`، `bot` و `caddy` را با یک دستور build و اجرا می‌کند. Caddy برای هر دو دامنه گواهی HTTPS می‌گیرد.

## اتصال اجزا

- ربات و Mini App به یک API و یک SQLite در `/data/finevpn.db` متصل‌اند.
- API از شبکه داخلی Docker به `http://vpn-panel:8000` متصل می‌شود.
- ساخت هر سرویس از API گروه اشتراک پنل اصلی، از مسیر `/api/subs/quick` انجام می‌شود.
- هنگام سفارش، یک گروه اشتراک و ۲۴ کانفیگ سازگار در یک عملیات پنل ساخته می‌شود.
- نام نمایشی تمام کانفیگ‌ها در کلاینت‌ها دقیقاً نام برند اصلی پنل یعنی `𝑭𝒊𝒏𝒆𝑽𝑷𝑵` باقی می‌ماند؛ نام گروه Subscription را مشتری جداگانه انتخاب می‌کند.
- حجم کل و مدت اعتبار برای کل گروه اعمال می‌شوند. سقف IP/دستگاه هم‌زمان روی هر یک از کانفیگ‌های گروه تنظیم می‌شود.
- لینک Subscription، لینک VLESS مستقیم، صفحه عمومی آمار و میزان مصرف از پنل خوانده و در بخش «سرویس‌های من» نمایش داده می‌شود.
- سرویس آزمایشی دقیقاً ۱ گیگابایت و ۷ روز است و هر حساب فقط یک مرتبه می‌تواند آن را دریافت کند.
- هیچ پنل جایگزینی از 3x-ui، Marzban یا Hiddify در منوی فروش باقی نمانده است.

## انتخاب سرویس توسط مشتری

در صفحه ساخت، مشتری نام گروه، حجم (۱ تا ۱۰٬۰۰۰ گیگابایت)، مدت (۱ تا ۳٬۶۵۰ روز) و سقف IP/دستگاه هم‌زمان هر کانفیگ را به‌صورت عدد دلخواه بین ۱ تا ۱۰۰ انتخاب می‌کند. قیمت فعلی بر اساس حجم و نرخ هر گیگ تنظیم‌شده توسط مدیر محاسبه می‌شود؛ مدت و سقف دستگاه در این نسخه ضریب قیمت جداگانه ندارند. ساخت گروه و ۲۴ کانفیگ داخلی آن در یک درخواست پنل انجام می‌شود. لینک اشتراک، کانفیگ مستقیم، صفحه آمار و مصرف کل گروه نمایش داده می‌شود.

## مدیریت سرویس‌ها

```bash
./logs.sh             # مشاهده لاگ همه سرویس‌ها
./logs.sh api          # لاگ API
./logs.sh bot          # لاگ ربات
./logs.sh vpn-panel    # لاگ پنل اصلی
./backup.sh            # پشتیبان دیتابیس و داده پنل
./stop.sh              # توقف بدون حذف داده‌ها
```

داده‌ها در volumeهای Docker پایدار می‌مانند. `docker compose down -v` را اجرا نکن؛ این دستور volumeها و داده‌ها را حذف می‌کند.

## زبان و ظاهر

- Mini App و پیام‌های ربات فارسی هستند؛ گزینه انگلیسی حذف شده است.
- تم روشن/تیره Mini App با دکمه بالای صفحه عوض می‌شود و در مرورگر ذخیره می‌شود.
- سطح Mini App، داشبورد پنل و صفحات Subscription از هویت بصری مشکی/سفید/قرمز مشترک استفاده می‌کنند.
- پرداخت کارت‌به‌کارت در گردش کار حذف شده است.

## اطلاعات مهم درباره نصب تازه و داده‌های قبلی

این ZIP سورس کد پنل را یکپارچه می‌کند؛ فایل وضعیت زمان اجرای پنل قبلی (`panel_state.json`)، کاربران، UUIDها و لینک‌های ایجادشده داخل ZIP سورس نبودند. اگر از قبل سرویس فعال داری، قبل از راه‌اندازی volume جدید، از داده‌های فعلی پنل خودت پشتیبان بگیر و آن را به volume `vpn_panel_data` منتقل کن. در غیر این صورت، نصب تازه با فضای داده جدید بالا می‌آید و کاربران/لینک‌های قدیمی خودبه‌خود منتقل نمی‌شوند.

اگر قبلاً پنل اصلی روی همین ماشین و با داده ذخیره‌شده اجرا شده، مقدار `VPN_PANEL_ADMIN_USERNAME` و `VPN_PANEL_ADMIN_PASSWORD` باید با اعتبارنامه ذخیره‌شده در همان داده تطابق داشته باشد. برای بازنشانی عامدانه از env، ابتدا از داده‌ها backup بگیر، سپس فقط در راه‌اندازی کنترل‌شده `PANEL_ADMIN_PASSWORD_RESET=1` قرار بده؛ پس از ورود موفق آن را به `0` برگردان.

## امنیت

- توکن قدیمی ربات که قبلاً در گفتگو ارسال شده بود افشاشده تلقی می‌شود. آن را در BotFather باطل کن و توکن جدید را فقط در `.env` بگذار.
- `.env` را برای کسی نفرست و در Git یا ZIP عمومی قرار نده.
- برای هر سرویس از رمز قوی و منحصربه‌فرد استفاده کن.
- تأیید رمزارز در این نسخه خودکارِ زنجیره‌ای نیست و باید سازوکار درگاه/تأیید مستقل تنظیم شود؛ ثبت TXID به‌تنهایی اثبات پرداخت نیست.

## حدود تست

در محیط ساخت، Python compilation و اعتبار نحوی JavaScript قابل اجراست. Docker Engine در محیط تولید فایل موجود نیست، بنابراین این بسته از داخل AWS شما build یا deploy نشده است. پس از اجرا، اول `https://<DOMAIN>/health`، `https://<VPN_PANEL_DOMAIN>/health` و سپس دستور `/paneltest` را از ربات مدیر بررسی کن. قبل از فروش، یک سفارش آزمایشی کم‌ریسک و ساخت/تحویل Subscription را تست کن.
